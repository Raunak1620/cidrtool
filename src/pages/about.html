What this site is

{{SITE}} is a set of free online utilities for network engineers, systems administrators and students: an IP address lookup, a CIDR and subnet calculator, a DNS lookup, a BGP and ASN lookup, a port number reference, an IP address converter and a bandwidth calculator.

How the tools get their data

  • Calculators (CIDR, subnet chart, IP converter, bandwidth) are computed in your browser with JavaScript.
  • DNS lookups use the public DNS-over-HTTPS services of Cloudflare and Google.
  • BGP and ASN data comes from the public RIPEstat data API, built from RIPE RIS route collectors.
  • IP geolocation comes from third-party IP intelligence services and is approximate.
  • Reference tables (ports, protocols, special-use address ranges) are compiled from IANA registries and the relevant RFCs.

Accuracy

We test the calculation logic and try to keep reference data correct, but no tool is perfect. Always verify results before applying them to production networks. If you find an error, please tell us and we will fix it.

How the site is funded

The site is supported by advertising, which keeps every tool free. Ads are kept away from the tool controls and results.
