How port numbers work

A port number identifies a service on a host, so many applications can share one IP address. Together with the transport protocol (TCP or UDP) it forms the destination of a connection. Ports are grouped by the IANA into three ranges:

  • 0–1023, well-known ports: assigned to core services such as SSH (22), DNS (53) and HTTPS (443).
  • 1024–49151, registered ports: assigned to specific applications on request, such as RADIUS (1812) or MySQL (3306).
  • 49152–65535, dynamic or ephemeral ports: used by clients as the source port of outgoing connections.

Using ports in firewall rules and ACLs

Allow only what is needed, in the direction it is needed. Management protocols such as SSH, SNMP, RDP and database ports should never be reachable from the internet. For stateless filters remember that return traffic uses an ephemeral port. Where a service has both an insecure and a TLS-protected version (HTTP/HTTPS, LDAP/LDAPS, syslog/syslog over TLS) prefer the protected one.

Ports you meet in network operations

  • Device management: SSH 22, NETCONF 830, SNMP 161/162, TACACS+ 49.
  • Network access control: RADIUS 1812/1813, CoA 3799, RadSec 2083. Cisco ISE also uses 8443 for portals, 9060 for the ERS API and 8910 for pxGrid.
  • Routing and resilience: BGP 179, LDP 646, BFD 3784/4784, HSRP 1985.
  • Wireless: CAPWAP control 5246 and data 5247.
  • Telemetry: syslog 514, NetFlow 2055 (by convention), IPFIX 4739, sFlow 6343, Zabbix 10050/10051.

IP protocol numbers

Some protocols have no ports at all because they run directly over IP. ACLs match them by protocol number or keyword.

Frequently asked questions

What is the difference between TCP and UDP ports?

They are separate number spaces. TCP port 53 and UDP port 53 are different endpoints, even though DNS uses both. A service listens on a specific protocol and port combination.

Which port does BGP use?

TCP 179. Both peers may initiate the session, so firewalls and control-plane ACLs must allow TCP 179 in both directions between peers.

Why does RADIUS have ports 1812 and 1645?

Early RADIUS deployments used 1645 and 1646, which conflicted with another service. The official ports are 1812 for authentication and 1813 for accounting. Some devices still default to the old pair.
