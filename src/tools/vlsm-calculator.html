Subnets you need

What is VLSM?

Variable Length Subnet Masking means using different prefix lengths inside the same network, so each subnet is only as big as it needs to be. Without it, a /24 split evenly into four /26 subnets wastes addresses on a point-to-point link that needs two. With VLSM you can give a 60-host VLAN a /26, a 28-host VLAN a /27 and a router link a /30 from the same block.

How the calculator allocates subnets

  1. For each requirement it finds the smallest block that holds the hosts, using usable hosts = 2n − 2 where n is the number of host bits.
  2. It sorts the requirements from largest to smallest.
  3. It places them one after another from the start of your network. Placing large blocks first keeps every block aligned to its own size, so nothing overlaps and no space is lost to gaps.

With the default example, 60 hosts needs a /26 (62 usable), 28 needs a /27 (30 usable), 10 needs a /28 (14 usable) and 2 needs a /30 (2 usable), and everything fits in the first 116 addresses of 192.168.10.0/24.

Point-to-point links and /31

A /30 wastes two addresses on a two-device link. RFC 3021 allows a /31 on point-to-point links, where both addresses are usable. Tick the box above to use /31 for any requirement of one or two hosts. Check that your devices support it first.

Leave room to grow

The plan sizes each subnet to exactly what you ask for. Add growth to the host counts before you calculate, for example 30 to 50 percent for user VLANs, because renumbering a subnet later is expensive.

Frequently asked questions

Why are subnets sorted largest first?

Block sizes are powers of two, and a block must start on a multiple of its own size. If you place large blocks first, every smaller block that follows is automatically aligned, so no addresses are wasted on gaps.

Does the order of my requirements matter?

No. The calculator sorts them itself. If two subnets are the same size, they keep the order you entered them in.

What happens if the subnets do not fit?

The calculator lists which subnet does not fit and why, and still allocates the ones that do. Use a larger network or reduce a host count.

Can I share my plan?

Yes. The page address updates as you edit, so you can copy the URL and send it to a colleague.
