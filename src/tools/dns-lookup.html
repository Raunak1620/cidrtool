How this DNS lookup works

Your browser sends the query directly to a public resolver using DNS over HTTPS (DoH), so the request is encrypted and no DNS server of ours is involved. You can choose Cloudflare (1.1.1.1) or Google (8.8.8.8), or compare both. Differences between them can point to caching, a recent change that has not propagated, or split-horizon DNS.

Common record types

  • A / AAAA: the IPv4 and IPv6 addresses for a name.
  • CNAME: an alias that points one name at another.
  • MX: mail servers for the domain, with a priority (lower is preferred).
  • NS: the authoritative name servers for the zone.
  • TXT: free-form text used for SPF, DKIM, DMARC and domain verification.
  • SOA: zone metadata such as the primary server, serial number and refresh timers.
  • CAA: which certificate authorities may issue certificates for the domain.
  • PTR: reverse DNS, mapping an IP address back to a name.

Reverse DNS lookups

Type an IPv4 or IPv6 address and the tool converts it to the right in-addr.arpa or ip6.arpa name and asks for the PTR record. Mail servers and many security tools check that a sending IP has a matching PTR record.

Checking email authentication records

Look up the TXT record on the domain for SPF (v=spf1 …), on _dmarc.example.com for DMARC and on selector._domainkey.example.com for DKIM. Use the "All common records" button to see most of a domain's configuration at once.

Frequently asked questions

Why do the two resolvers show different results?

Each resolver caches answers for the record's TTL. After a change, one resolver may still serve the old value until its cache expires. Wait for the TTL shown in the results, then query again.

What does NXDOMAIN mean?

The name does not exist. Check the spelling, or confirm the record has been created in the authoritative zone.

What does the DNSSEC validated badge mean?

The resolver checked the DNSSEC signatures for the answer and found them valid. Its absence means the domain is not signed or the resolver did not validate it.

Why is there no ANY record type?

Major public resolvers no longer return full ANY responses (RFC 8482). Use the "All common records" button instead.

Is DNS propagation checking possible here?

You can compare two global resolvers, which catches most cache-related delays. Full propagation checking across many regions requires probes in many locations, which a browser-based tool cannot provide.
