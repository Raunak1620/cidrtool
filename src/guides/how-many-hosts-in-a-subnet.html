A normal IPv4 subnet holds 2h − 2 usable host addresses, where h is the number of host bits, which is 32 minus the prefix length. A /24 has 8 host bits, so 28 − 2 = 254 usable hosts. The two addresses that are subtracted are the network address and the broadcast address, which cannot be assigned to devices.

The formula and why you subtract two

Every host bit can be 0 or 1, so a subnet with h host bits contains 2h addresses. Two of them have a special role:

  • The first address, where every host bit is 0, identifies the subnet itself. It is the network address.
  • The last address, where every host bit is 1, is the directed broadcast address for the subnet.

For a /26 the working is: 32 − 26 = 6 host bits, 26 = 64 addresses, 64 − 2 = 62 usable hosts. In 192.168.10.64/26, the network address is 192.168.10.64, the broadcast address is 192.168.10.127 and hosts use 192.168.10.65 to 192.168.10.126.

The /31 and /32 exceptions

The subtract-two rule does not apply to the two smallest prefixes.

  • /32 is a single address. It is used for loopback interfaces, router IDs, host routes and ACL entries that match exactly one device.
  • /31 has two addresses and both are usable. RFC 3021 allows this on point-to-point links, where there is no need for a network or broadcast address. It halves the address use of a link compared with a /30. Most modern routers and switches support /31 links, but check the platforms at both ends before relying on it.

A /30 gives two usable addresses out of four, which is why it was the traditional choice for point-to-point links before /31 support was common.

Working backwards: from a host count to a prefix

When you know how many devices a subnet must hold, find the smallest number of host bits h where 2h − 2 is at least that number. The prefix is then 32 − h.

Always size for the number you expect to have in a few years, not the number you have today. If a segment has 100 devices now and may reach 150, a /25 is too small and a /24 with 254 usable addresses is the next size up. Renumbering a live subnet is more work than reserving extra space at the start. When you need to size several subnets from one block, the VLSM tutorial shows how to fit them together.

Why the real number is often lower

The formula gives the number of addresses available. The number you can give to end devices is usually smaller.

  • The default gateway uses one address. A redundant pair with a virtual IP, such as HSRP or VRRP, uses three: one for each router and one for the virtual address.
  • Servers, printers, access points and network devices that need static addresses reduce the DHCP pool.
  • Some DHCP designs exclude a range for static assignments.
  • Cloud platforms reserve addresses of their own. AWS reserves five addresses in every VPC subnet, so a /28 with 16 addresses offers 11 for your resources. Azure also reserves five addresses per subnet.

IPv6 does not follow this rule

IPv6 has no broadcast address, so there is nothing to subtract. Almost every IPv6 subnet is a /64, which holds 264 addresses. Host counts are not a planning concern in the same way. The IPv4 and IPv6 subnetting comparison explains how address planning changes.

Frequently asked questions

How many usable hosts are in a /24?

254. A /24 has 256 addresses. The network address and the broadcast address are not usable, which leaves 254.

How many usable hosts are in a /27?

30. A /27 has 5 host bits, so 25 = 32 addresses and 32 − 2 = 30 usable hosts. See the /27 reference page.

Why is the formula 2^n minus 2 and not just 2^n?

The first address in the block names the subnet and the last address is the broadcast address for that subnet. Both are reserved, so only 2n minus 2 addresses can be assigned to hosts.

Is a /31 subnet usable?

Yes, on point-to-point links. RFC 3021 lets both addresses of a /31 be used as host addresses. It is not meant for subnets with more than two devices.
