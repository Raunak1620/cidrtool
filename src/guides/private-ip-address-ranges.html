RFC 1918 reserves three blocks of IPv4 space for private networks. Anyone can use them inside their own network without registering, and routers on the internet do not forward them.

The three RFC 1918 ranges

CIDR blockRangeAddressesTypical use
10.0.0.0/810.0.0.0 – 10.255.255.25516,777,216Large enterprises, data centres, cloud networks
172.16.0.0/12172.16.0.0 – 172.31.255.2551,048,576Mid-size networks, container platforms
192.168.0.0/16192.168.0.0 – 192.168.255.25565,536Homes, small offices, lab networks

The middle block is a /12, so it ends at 172.31.255.255. Addresses such as 172.32.1.1 are public. This is a common mistake.

Other special IPv4 ranges

  • 100.64.0.0/10 (RFC 6598) is shared address space for carrier-grade NAT. ISPs use it between customers and their NAT gateways.
  • 169.254.0.0/16 (RFC 3927) is link-local. A host that fails to get a DHCP lease often assigns itself an address here.
  • 127.0.0.0/8 is loopback. 127.0.0.1 always means "this machine".
  • 192.0.2.0/24, 198.51.100.0/24 and 203.0.113.0/24 (RFC 5737) are reserved for documentation and examples.

Private addresses in IPv6

IPv6 has unique local addresses in fc00::/7, which in practice means fd00::/8 with a random 40-bit global ID. They are the equivalent of RFC 1918 space. IPv6 also has link-local addresses in fe80::/10, which every IPv6 interface uses for neighbour discovery.

Choosing a range

Many home routers default to 192.168.0.0/24 or 192.168.1.0/24. If you connect to a company VPN that uses the same subnet, routing breaks because both sides think the address is local. For that reason, pick something less common for any network you may need to join to another: a 10.x.y.0/24 with unusual values, or a block from 172.16.0.0/12. For a company, plan the 10.0.0.0/8 space in advance by giving each site or region a fixed block, so sites can be summarized and never overlap.

Frequently asked questions

Can private addresses reach the internet?

Not directly. They need network address translation (NAT) at the edge, which rewrites them to a public address.

Is 172.20.1.1 a private address?

Yes. It lies inside 172.16.0.0/12.

Is 100.64.0.1 private?

It is not RFC 1918 private space, but it is not publicly routable either. It is reserved for carrier-grade NAT.

Can two companies use the same private range?

Yes, and they usually do. Overlap only becomes a problem when the networks are connected, for example by a VPN or after a merger.
