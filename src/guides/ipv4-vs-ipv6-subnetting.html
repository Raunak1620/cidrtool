Both IP versions split an address into a network prefix and a host part, and both write the split as a prefix length. The difference is scale. IPv4 has 32 bits, so every address is precious and you subnet to avoid waste. IPv6 has 128 bits, so you subnet for structure, not to save addresses.

The /64 convention

In IPv6 the standard size for a subnet that hosts devices is a /64. The lower 64 bits are the interface identifier, and features such as SLAAC (stateless address autoconfiguration) depend on that size. A single /64 holds 264 = 18,446,744,073,709,551,616 addresses. You do not count hosts to pick a prefix length; you give each VLAN or segment its own /64.

Allocating a /48 to a site gives 16 bits of subnet space, so you can number subnets from 0000 to ffff in the fourth group of the address.

Differences from IPv4 in practice

  • No broadcast. IPv6 uses multicast instead, so there is no broadcast address to reserve. Only the all-zeros address in a subnet (the subnet-router anycast address) is special.
  • No host counting. You do not use 2n − 2. Subnets are sized by convention.
  • Hex nibble boundaries. Each hex digit is 4 bits, so prefixes that are multiples of 4 (/48, /52, /56, /60, /64) land on a digit boundary and are easy to read.
  • Addresses are abbreviated. Leading zeros in a group are dropped, and one run of all-zero groups becomes ::.

Point-to-point links and loopbacks

Router links are often given a /127 (RFC 6164), which avoids a problem where a packet sent to the unused address on a /64 link can be bounced between two routers. Some operators still use /64 on links for simplicity, and others use /126. Loopback addresses are a single /128.

A worked example

You are given 2001:db8:abcd::/48. To create the subnet for VLAN 10, use the fourth group: 2001:db8:abcd:a::/64. VLAN 20 can be 2001:db8:abcd:14::/64 (20 is 0x14). Writing the VLAN number in hex into the subnet field is a simple convention that keeps the plan readable. 2001:db8::/32 is the range reserved for documentation, so it is safe in examples.

Frequently asked questions

Can I use a prefix longer than /64 for a LAN?

Technically yes, but SLAAC will not work, and some features assume a /64. Use /64 for LANs.

How many addresses are in a /48?

280, about 1.2 × 1024, which is 65,536 /64 subnets.

Do I still need NAT with IPv6?

Usually not. Devices get globally routable addresses, and a stateful firewall provides the protection that NAT is often mistaken for.
